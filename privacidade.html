Política de privacidade

Última revisão: 14 de outubro de 2026

Quem somos

Este site é operado pela DD Digital. Para qualquer questão sobre esta política, contacte-nos através de dddigital.pt@gmail.com.

Que dados recolhemos

Recolhemos apenas os dados que nos fornece voluntariamente ao preencher o formulário de contacto:

  • Nome
  • Email
  • Telefone (opcional)
  • Tipo de projeto e mensagem que escreve

Este site não usa cookies de análise nem de publicidade, e não recolhe dados automaticamente para além do que é necessário para o formulário funcionar.

Como usamos os dados

Os dados do formulário são usados apenas para responder ao seu pedido de contacto ou orçamento. O envio é processado pelo serviço externo Web3Forms, que entrega a mensagem diretamente no nosso email — não guardamos uma base de dados própria com os seus dados.

Com quem partilhamos os dados

Não vendemos nem partilhamos os seus dados com terceiros para fins de marketing. Os dados do formulário passam pela Web3Forms (processador técnico do envio de email) e, depois de recebidos, ficam apenas na nossa caixa de correio.

Quanto tempo guardamos os dados

Guardamos as mensagens recebidas por email durante o tempo necessário para tratar o seu pedido e, depois, enquanto for razoável para fins de histórico comercial, salvo se nos pedir para as eliminarmos antes.

Os seus direitos

Pode, em qualquer momento, pedir-nos para aceder, corrigir ou eliminar os seus dados, escrevendo para dddigital.pt@gmail.com. Tem também o direito de apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD).
